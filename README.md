# DiffuScore

DiffuScore is a web-based editor for creating, editing, and organizing personalized sound diffusion scores for acousmatic music performances.

Designed for performers working with loudspeaker orchestras (acousmonia), DiffuScore provides a flexible visual workspace where stereo audio representations and graphical annotations coexist on a shared timeline.

## Stack

- React 19 + TypeScript
- [Vite+](https://viteplus.dev) (`vp`): dev server, build, lint (Oxlint), format (Oxfmt), test (Vitest)
- TanStack Router
- Tailwind CSS v4
